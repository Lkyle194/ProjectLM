## 🌟 1. Vision du Jeu

### 🎯 Le Concept en Une Phrase

**Project LM est un MMORPG où l'intelligence artificielle observe, analyse et récompense le comportement authentique de chaque joueur, rendant chaque personnage unique et irremplaçable.**

### 🌍 Contexte 2026

| Statistique | Valeur | Signification |
|-------------|--------|---------------|
| 💰 Marché mondial | **180+ milliards $** | Opportunité massive |
| 📱 Part mobile | **49%** | Domination du mobile |
| 🤖 Jeux Steam avec IA | **7 000+** | 1 jeu sur 3 utilise l'IA |
| 🎮 Jeux anti-méta | **0** | Aucun concurrent direct |

### 💡 Pourquoi Maintenant ?

```
┌─────────────────────────────────────────────────────────────┐
│  🔥 Lassitude de la méta → Les joueurs fuient les builds    │
│     figés (WoW Classic decline, XDefiant shutdown)          │
│                                                             │
│  🚀 IA native en plein essor → Mais AUCUN jeu n'utilise    │
│     l'IA pour l'observation comportementale                 │
│                                                             │
│  🎯 Hybrid-casual domine → 2-3x meilleure rétention J7     │
│     que l'hypercasual — profondeur accessible               │
│                                                             │
│  ✨ Crise d'authenticité → Backlash contre l'IA "slop" —   │
│     Project LM utilise l'IA AU SERVICE du joueur            │
└─────────────────────────────────────────────────────────────┘
```

### 🎭 Positionnement Stratégique

| Dimension | Positionnement |
|-----------|----------------|
| **Genre** | 🎮 MMORPG narratif émergent / Action-RPG social |
| **Cible primaire** | 🎯 Joueurs MMORPG lassés de la méta (25-35 ans, PC) |
| **Cible secondaire** | 🌱 Joueurs casual valorisant la découverte organique |

## ⚙️ 2. Mécaniques Cœurs

### 🧠 2.1 Système d'Observation Comportementale

> **💎 Cœur du jeu** — remplace les arbres de talents traditionnels par une analyse dynamique du comportement.

#### 📊 Les Dimensions Comportementales

Chaque action du joueur est classifiée dans des **dimensions comportementales**. Les jauges d'XP cachées évoluent en continu :

| Dimension | Comportements | Archétypes Résultants |
|-----------|---------------|----------------------|
| ⚔️ **Bravoure** | Attaquer en premier, provoquer, combattre à plusieurs | Guerrier, Paladin, Berserker |
| 🗡️ **Ruse** | Attaques sournoises, retraites stratégiques, embuscades | Voleur, Assassin, Ranger |
| 🛡️ **Sacrifice** | Soigner, protéger, prendre des dégâts pour l'équipe | Clerc, Gardien, Templier |
| 🔍 **Curiosité** | Explorer, interagir avec le décor, lire des documents | Mage, Érudit, Alchimiste |
| 🌀 **Instabilité** | Comportements erratiques, changement fréquent de style | Démoniste, Chaos Knight |

#### 🔒 Règles Fondamentales

```yaml
✅ Les jauges sont STRICTEMENT INVISIBLES
   → Pas de barres, pas de pourcentages, pas d'indices chiffrés

✅ Les comportements incohérents RÉDUISENT la jauge
   → Impossible de farmer une dimension en spamant

✅ Le système détecte et pénalise les comportements artificiels
   → Anti-meta intégré nativement

✅ Une action marquante > 100 actions banales
   → Première victoire contre un boss, sauvetage d'équipier
```

#### 🎭 Feedback au Joueur (Équilibre Critique)

> ⚠️ **Leçon apprise :** L'invisibilité totale frustre. Solution hybride :

- 🗣️ **Indices narratifs via le LLM** : « Vous sentez une affinité naissante avec l'ombre... »
- 👤 **PNJ commentent votre style** : « Tes pas sont lourds, guerrier — mais j'ai vu une lueur de ruse dans tes yeux. »
- 📖 **Bestiaire de compétences** : Les compétences débloquées sont une surprise, mais leur existence est connue
- 🌙 **Rêves/visions nocturnes** : Montrent des archétypes possibles

---

### 🎯 2.2 Déblocage Dynamique des Compétences

Quand une jauge comportementale atteint un seuil critique, la compétence entre en état **« d'éveil latent »**.

#### 🔄 Processus en 3 Phases

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Phase 1: ÉVEIL LATENT                                      │
│  └─→ La jauge dépasse 90%                                   │
│  └─→ Le joueur ressent une "tension" narrative              │
│                                                             │
│  Phase 2: DÉCLENCHEMENT CONTEXTUEL                          │
│  └─→ Un événement du monde déclenche la manifestation       │
│  └─→ Combat intense, exploration sacrée, moment social fort │
│                                                             │
│  Phase 3: INTÉGRATION                                       │
│  └─→ La version normale rejoint le kit permanent            │
│  └─→ Le joueur peut maintenant l'utiliser librement         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 📝 Exemple de Template de Compétence

```yaml
Nom: Invocation du Squelette Mineur
Type: Invocation
Source d'XP: Ruse + Sacrifice
Déclencheur Ultime: Combat en infériorité numérique, allié KO
Effet Ultime: Invocation d'un squelette géant qui terrasse les ennemis proches
Effet Normal: Invoque un squelette mineur pendant 30s

Évolutions Possibles:
  A: Combattre au CaC à côté du squelette → Armure d'Os (réduction dégâts)
  B: Invoquer 50+ fois → Squelette Archer (dégâts à distance)
```

### 🎁 2.3 Loot Contextuel

Les objets sont générés dynamiquement par l'IA en fonction du comportement récent et du contexte de jeu.

#### 🏆 Types d'Objets Contextuels

| Type | Exemple | Histoire |
|------|---------|----------|
| 🎯 **Récompense de playstyle** | « Dague Traîtresse » | Joueur solo qui fuit les combats de groupe — dégâts accrus en isolement |
| ⚔️ **Récompense de défi** | « Épée d'Ombre » | Vaincre un boss ombre après plusieurs tentatives — dégâts d'ombre |
| 🤝 **Récompense sociale** | « Baguette du Dernier Rempart » | Healer qui a perdu plusieurs équipiers — soin explosif au KO d'un allié |
| 🗺️ **Récompense d'exploration** | « Cape de l'Observateur » | Joueur qui explore plutôt que combattre — détection améliorée |

---

### 🔄 2.4 Évolution et Fusion des Compétences

**🆕 Nouveauté 2026** : Les compétences **fusionnent** ou **évoluent** en fonction de l'évolution comportementale du joueur.

#### 📈 Exemple de Transition Complète

```
Stade 1: Invocateur (invoque des squelettes)
   ↓
   Le joueur combat au corps-à-corps près de ses invocations
   ↓
Stade 2: Débloque "Armure d'Os" (réduction de dégâts)
   ↓
   Le joueur n'invoque plus, encaisse les dégâts en première ligne
   ↓
Stade 3: Armure d'Os devient activation sans invocation
   ↓
🎯 TRANSITION: D'invocateur → Chevalier de la Mort
```

### 🛡️ 2.5 Anti-Meta System

L'IA détecte et pénalise les comportements artificiels ou répétitifs :

| Détection | Action | Résultat |
|-----------|--------|----------|
| 🔍 **Farming** | Spam d'actions incohérentes | Réduction de gain d'XP |
| ⚠️ **Pénalité progressive** | Comportements artificiels répétés | Suggestion → Verrouillage temporaire |
| ✨ **Récompense authenticité** | Comportements naturels et variés | Bonus d'XP caché |

> **🎯 Anti-meta 2026** : Le système est lui-même adaptatif — si les joueurs trouvent une méta, l'IA ajuste les seuils. C'est un jeu du chat et de la souris infini.

## 📈 3. Progression

### 🎯 3.1 Philosophie — « Deep but Accessible »

Inspiré du **hybrid-casual** 2026 : accessible en 5 minutes, profond pour 500 heures.

| Niveau | Durée | Ce qui se débloque |
|--------|-------|-------------------|
| 🌱 **Découverte** | 0-2h | Contrôles, premier combat, 1ère compétence automatique |
| 🌿 **Éveil** | 2-10h | 2-3 compétences, compréhension que le style compte |
| 🌳 **Affirmation** | 10-50h | Spécialisation, premières fusions, loot contextuel significatif |
| ⭐ **Maîtrise** | 50-200h | Build unique, anti-meta actif, contenu de groupe |
| 👑 **Légende** | 200h+ | Le joueur est une « espèce » unique — pas de clone possible |

---

### 👁️ 3.2 Progression Visible vs Invisible

| Type | Visible ? | Exemples |
|------|-----------|----------|
| 📊 **Level classique** | ✅ Oui | Niveau global, HP, mana (repères familiers) |
| 🎯 **Compétences débloquées** | ✅ Oui | Barre de compétences, inventaire de sorts |
| 🔒 **Jauges comportementales** | ❌ **Non** | Cachées — le mystère fait partie du jeu |
| 🎁 **Loot potentiel** | 🌫️ Partiel | « Un objet intéressant pourrait apparaître bientôt... » |
| 👤 **Archétype dominant** | 🎭 Indirect | Via les commentaires des PNJ et les visions |
| 🔄 **Fusions possibles** | ❌ **Non** | Découverte pure — guide du jeu inexistant |

---

### 🤝 3.3 Progression Sociale

- 🏰 **Guildes d'archétypes** : Basées sur les comportements dominants, pas le choix
- 🔗 **Synergies d'équipe** : L'IA détecte les complémentarités comportementales
- 🌍 **Événements mondiaux adaptatifs** : Le serveur entier doit adopter certains comportements

---

### 🏆 3.4 Système de Renom

| Renom | Comportement | Récompenses |
|-------|--------------|-------------|
| 🦸 **Héros** | Aide aux nouveaux, partage, sauvetages | Quêtes exclusives, réduction prix marchands |
| ⚔️ **Mercenaire** | Efficacité maximale, peu d'interactions | Contrats spéciaux, zones dangereuses |
| 🐺 **Solitaire** | Jeu en solo, exploration autonome | Objets uniques introuvables en groupe |
| 👑 **Meneur** | Organisation, stratégies d'équipe | Buffs d'équipe, titre « Stratège » |

---

### 🌙 3.5 Progression Hors-Ligne

Quand le joueur se déconnecte, son personnage continue d'exister :

- 🤖 **Autonomie limitée** : Le PNJ « fantôme » agit selon le comportement enregistré
- 🎁 **Récompenses au retour** : Butin collecté, réputation gagnée ou perdue
- ⚠️ **Conséquence** : Abandonner son groupe en pleine quête → réputation baisse même déconnecté

## 🎨 4. Direction Artistique

### 🖼️ 4.1 Style — Dark Fantasy Émotionnelle

**Inspirations** : *Darkest Dungeon* × *Hollow Knight* × *Tunic*

| Aspect | Direction | Inspiration |
|--------|-----------|-------------|
| 🎨 **Palette** | Sombres saturées — bleus profonds, violets, ors tamisés | Darkest Dungeon, Rain World |
| 💡 **Éclairage** | Volumétrique, dynamique — ombres douces, lumières de bougie | Tunic, Hollow Knight |
| 👤 **Personnages** | Silhouettes distinctes, armures/capes qui évoluent avec le build | Dark Souls, Destiny |
| 👾 **Monstres** | Designs organiques, asymétriques — pas de bestiaire générique | Darkest Dungeon, Fear & Hunger |
| 🖥️ **UI** | Diégétique — les éléments font partie du monde (grimoire = menu) | Dead Space, Tunic |
| 🎬 **Animation** | Procédurales légères (pas de motion capture coûteuse) | Dead Cells, Hades |

---

### 🔄 4.2 Évolution Visuelle du Personnage

L'apparence change **en fonction du comportement**, pas de l'équipement :

| Comportement | Évolution Visuelle |
|--------------|-------------------|
| 🛡️ **Protecteur** | Armure imposante, bouclier lumineux |
| 🗡️ **Furtif** | Cape sombre, silhouette élancée, yeux lumineux |
| 🔮 **Mage explorateur** | Aura scintillante, runes visibles sur la peau |
| 🌀 **Chaotique** | Effets visuels instables, particules erratiques |

> **💡 Avantage 2026** : Pas besoin de modéliser 50 sets d'armure — l'apparence émerge du comportement via des shaders et des particules.

### 🗺️ 4.3 Environnements

| Biome | Ambiance | Gameplay |
|-------|----------|----------|
| 🌲 **Forêt d'Échos** | Sépia, bruine, arbres fossilisés | Exploration, premiers combats |
| 💀 **Catacombes des Origines** | Bleu froid, torches vacillantes | Combat dense, pièges, premier boss |
| ⛰️ **Cime des Décisions** | Coucher de soleil permanent, vent fort | Parkour, combats aériens |
| 📚 **Bibliothèque Vivante** | Jaune chaud, livres volants | Quêtes de connaissance, puzzles |
| 🌌 **Le Vide** | Aucune couleur, silhouette uniquement | Zone secrète — défi ultime |

---

### 🤖 4.4 Stratégie de Production Artistique

**Approche 2026 — Hybride IA/Artisanat :**

1. 🎨 **Concepts** : Artiste humain définit le style (50-100 concepts clés)
2. 🖼️ **Textures** : IA génère des variations → artiste sélectionne et retouche
3. 🗿 **Modèles 3D** : Modélisation humaine des assets clés
4. 🎬 **Animation** : Procédurale + quelques animations clés faites main
5. 🖥️ **UI** : 100% design humain — pas d'IA dans l'interface

> ⚠️ **Règle absolue** : Aucun asset généré par IA n'entre directement dans le jeu final sans curation humaine.

## 💎 6. Monétisation

### 🎯 6.1 Philosophie — « Play and Own », Pas Pay-to-Win

> **💎 Principe fondateur** : 30% des jeux seulement utilisent la monétisation hybride — plus grande opportunité inexploitée.

#### ✅ Principes

- 🔒 **Jamais de pay-to-win** — l'intégrité du système comportemental est sacrée
- 🎨 **Cosmétique uniquement** — l'apparence, pas la puissance
- 🏆 **Battle Pass comportemental** — récompenses basées sur le style, pas le temps
- 📺 **Pas de publicités intempestives** — vidéos récompensées optionnelles uniquement

---

### 💰 6.2 Modèle de Revenus

| Source | % Revenu | Description |
|--------|----------|-------------|
| 🏆 **Battle Pass (saisonnier)** | **45%** | 3 mois, récompenses cosmétiques + titres + emotes |
| 🎨 **Boutique cosmétique** | **30%** | Skins, effets de particules, capes, familiers |
| 💎 **Abonnement Premium** | **15%** | Plus de slots, badges exclusifs, accès anticipé |
| 📺 **Vidéos récompensées** | **10%** | Bonus d'XP cosmétique, apparence temporaire |

---

### 🏆 6.3 Battle Pass Comportemental (Innovation)

Au lieu de récompenser le temps de jeu, le Battle Pass récompense la **diversité comportementale** :

| Niveau | Défi | Récompense |
|--------|------|------------|
| 1 | 🛡️ Agir en protecteur 10 fois | Cape « Ombrageuse » (effet visuel) |
| 2 | 🗺️ Explorer 5 zones cachées | Emote « Méditation » |

| 4 | ⚔️ Survivre à 3 combats en infériorité | Effet de particules « Résilience » |
| 5 | 🔄 Changer d'archétype dominant | Apparence « Caméléon » |
